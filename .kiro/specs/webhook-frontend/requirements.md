# Requirements Document

## Project Description (Input)
為現有的 webhook 工具建立前端頁面

## 系統概述
這是一個為強大的 Webhook Gateway 後端系統建立現代化前端管理介面的專案。目前系統採用 FastAPI 架構，提供完整的 webhook 接收、驗證、處理和分發功能。本前端介面將提供直觀的用戶體驗來管理系統資源和監控運營狀態。

## 功能需求

### 1. 認證與授權
- **Bearer Token 認證**: 使用後端 API 金鑰進行身份驗證
- **會話管理**: 自動處理認證狀態和過期處理
- **安全存儲**: 安全存儲認證憑據

### 2. 儀表板 (Dashboard)
- **系統總覽統計**:
  - 總 webhook 事件數量
  - 活躍訂閱數量
  - 系統健康狀態指示器
  - 近期活動趨勢圖表
- **即時更新**: 使用 WebSocket 或輪詢獲取最新數據
- **快速操作**: 常用功能的快捷按鈕

### 3. 來源管理 (Sources Management)
- **來源列表**: 分頁顯示所有 webhook 來源
- **來源詳情**: 查看來源配置和統計信息
- **創建來源**: 支援多種簽名驗證類型
  - GitHub 風格驗證
  - Stripe 風格驗證
  - 通用 HMAC 驗證
- **編輯來源**: 修改來源配置和密鑰
- **刪除來源**: 支援軟刪除機制
- **狀態指示**: 顯示來源活躍狀態和錯誤率

### 4. 主題管理 (Topics Management)
- **主題列表**: 按來源分組顯示主題
- **主題詳情**: 查看主題統計和關聯訂閱
- **創建主題**: 支援自定義主題名稱和描述
- **編輯主題**: 修改主題信息
- **刪除主題**: 支援主題移除操作
- **驗證規則**: 確保主題名稱格式正確

### 5. 訂閱管理 (Subscriptions Management)
- **訂閱列表**: 多維度篩選和搜尋
  - 按主題篩選
  - 按狀態篩選 (活躍/非活躍)
  - 按訂閱者名稱搜尋
- **訂閱詳情**: 顯示訂閱統計和歷史記錄
- **創建訂閱**: 設定目標 URL 和訂閱者信息
- **編輯訂閱**: 修改訂閱配置
- **啟用/停用**: 支援訂閱狀態切換
- **批量操作**: 支援多選批量啟用/停用

### 6. 統計與監控 (Statistics & Monitoring)
- **總覽統計**: 系統層級統計數據
- **活動統計**: 按時間範圍顯示活動趨勢
- **來源統計**: 按來源分組的統計數據
- **錯誤追蹤**: 顯示失敗率和錯誤詳情
- **圖表視覺化**: 使用圖表庫呈現數據趨勢
- **匯出功能**: 支援統計數據匯出

### 7. 事件日誌 (Event Logs)
- **日誌查詢**: 支援多條件篩選查詢
- **日誌詳情**: 顯示完整的事件內容和元數據
- **即時監控**: 實時顯示新接收的事件
- **分頁載入**: 處理大量日誌數據的高效載入
- **搜尋功能**: 支援關鍵字搜尋和過濾

### 8. 系統管理 (System Administration)
- **健康檢查**: 顯示系統各組件健康狀態
- **認證驗證器資訊**: 顯示支援的驗證類型
- **系統指標**: Prometheus 指標展示
- **配置查看**: 系統配置和環境資訊

## 非功能需求

### 1. 用戶體驗 (User Experience)
- **響應式設計**: 支援桌面和移動設備
- **現代化介面**: 使用現代前端框架和設計系統
- **直觀導航**: 清晰的導航結構和麵包屑
- **載入狀態**: 適當的載入指示器和錯誤處理
- **無障礙訪問**: 遵循無障礙設計原則

### 2. 技術架構 (Technical Architecture)
- **前端框架**: React/Vue.js + TypeScript
- **狀態管理**: Redux/Zustand 或類似解決方案
- **HTTP 客戶端**: Axios 或 Fetch API
- **圖表庫**: Chart.js、D3.js 或類似圖表解決方案
- **表單處理**: React Hook Form 或類似表單驗證庫
- **路由管理**: React Router 或 Vue Router

### 3. 性能要求 (Performance Requirements)
- **載入時間**: 首頁載入時間 < 2秒
- **API 響應**: 一般操作響應時間 < 500ms
- **記憶體使用**: 合理記憶體消耗，不造成記憶體洩漏
- **網路優化**: 支援請求去重和智慧快取

### 4. 安全性 (Security)
- **認證保護**: 所有敏感操作都需要認證
- **輸入驗證**: 前端輸入驗證和清理
- **HTTPS 強制**: 所有通訊使用 HTTPS
- **錯誤處理**: 不暴露敏感系統資訊

### 5. 錯誤處理 (Error Handling)
- **用戶友好錯誤訊息**: 清晰的錯誤說明
- **重試機制**: 網路錯誤自動重試
- **離線支援**: 網路中斷時的適當處理
- **操作確認**: 危險操作需要確認對話框

## 整合需求

### 1. API 整合 (API Integration)
- **RESTful API**: 與後端 REST API 完整整合
- **錯誤處理**: 統一錯誤處理和顯示
- **請求攔截**: 統一請求/響應攔截處理
- **版本處理**: 支援 API 版本管理

### 2. 認證整合 (Authentication Integration)
- **Token 管理**: 自動 Token 刷新和存儲
- **登出功能**: 清除認證狀態
- **權限控制**: 基於角色的功能訪問控制
